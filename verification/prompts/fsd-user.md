# 需求文件：壽險新保件保費試算（Life Premium）

**文件代碼：** LIFE-PREMIUM　**版本：** v1.0　**日期：** 2026-09-08

## 業務情境

壽險業務員或訪客輸入被保人基本資料（年齡、性別、保額、繳費年期），系統即時計算年繳與月繳保費，協助投保決策。

## 使用者角色

| 角色 | 說明 |
|------|------|
| 業務員（Agent） | 登入後為客戶試算保費，並保留試算紀錄 |
| 訪客（Guest） | 於官網公開頁面試算保費（不留紀錄，或以匿名代理人記錄） |

## 核心業務規則

| 規則編號 | 說明 |
|---------|------|
| BR-001 | 被保人年齡 0～70 歲 |
| BR-002 | 保額 100～5,000 萬元 |
| BR-003 | 繳費年期：10 / 20 / 30 / 99 年 |
| BR-004 | 年繳保費 = ROUND(保額 ÷ 1000 × 費率) |
| BR-005 | 月繳保費 = ROUND(年繳 ÷ 12 × 1.03) |

## 費率表（節錄）

商品 `LIFE-WL-01`（終身壽險）費率表版本 v1（每千元保額費率，依年齡/性別/繳費年期查表）：

| 年齡 | 性別 | 繳費年期 | 費率（每千元） |
|------|------|---------|---------------|
| 35 | M | 20 | 12.50 |
| 35 | F | 20 | 11.20 |
| 30 | M | 20 | 10.80 |
| 40 | M | 20 | 14.90 |

## 計算範例

| 項目 | 值 |
|------|-----|
| 商品 | LIFE-WL-01（終身壽險） |
| 年齡 / 性別 | 35 歲 / 男性 |
| 保額 | 1,000 萬元 |
| 繳費年期 | 20 年 |
| 費率 | 12.50（每千元） |
| 年繳保費 | 125,000 元 |
| 月繳保費 | 10,729 元 |

> 換算：1000 萬 ÷ 1000 × 12.50 = 125,000（年繳）；125,000 ÷ 12 × 1.03 = 10,729.1666… → ROUND = 10,729（月繳）。

## 非功能需求（概要）

- API 回應時間 ≤ 500ms
- 試算紀錄需保留供稽核（含業務員 ID、試算時間、輸入參數、計算結果）
- 需支援之後費率表版本更新（RateTableVersion），不可覆蓋歷史試算紀錄所依據的費率

## 例外情境

- 年齡超出 0～70 歲 → 拒絕試算，回傳錯誤訊息
- 保額超出 100～5,000 萬元 → 拒絕試算
- 繳費年期不在 {10,20,30,99} → 拒絕試算
- 查無對應費率（年齡/性別/繳費年期組合未建檔）→ 回傳「查無費率」錯誤
